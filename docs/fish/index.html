グリオン釣り図鑑

グリオンで釣れる魚の図鑑。釣れる場所・竿・餌・時刻・天気・値段・使い道を、魚ごとにまとめています。

この図鑑の見方

  • 道具屋で釣り竿と餌を買い、水辺でN(または/fish)を押すと釣りを始めます。
  • 竿: 竿力が魚の格に足りないと糸が切れます。表の竿か、それより強い竿を使ってください。
  • 餌・時刻・天気・曜日: 釣り帖に出る手がかりと同じです。「〜のみ」はその時しか掛からず、「〜に多い」はその時に掛かりやすくなります。
  • 魚問屋: 町の「魚問屋の主人」が買い取ります。今日の目玉の魚は日替わりで高値です。買い取りの上限は約1週間で戻ります。
  • 伝説魚: 餌や時刻は載せていません。釣り帖のうわさを手がかりに探してください。

数字はゲームのデータ表から自動で作っています。内容はゲームの更新で変わることがあります。
