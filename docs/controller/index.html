コントローラーで遊ぶ

グリモワールオンライン(グリオン)は、Xbox形式のゲームパッドで遊べます。キーボード・マウスと混ぜて使っても大丈夫です。

十字キー窓の中ではカーソル。窓の外では回復や強化を掛ける仲間を選ぶ(下を見てください)↑↓←→・F1〜F6

仲間を選ぶ(十字キー)

回復や強化の魔法を掛ける相手(支援対象)は、窓が開いていない時の十字キーで選びます。敵への狙いはそのまま残るので、回復してすぐ攻撃に戻れます。

  • ↑ ↓ パーティの仲間を1人ずつ選ぶ(キーボードの F1〜F6 の順)
  • ← 自分を選ぶ(F1)
  • → 仲間の選択を外す
画面左のパーティ欄で、選ばれている仲間の枠が光ります。

ボタンに無い操作

休憩・釣り・クエストの一覧・ステータス・スキル・フレンド・ワイドスキャン・カード帳などは、Y のメインメニューから開けます。

チャットの文を打つ時はキーボードを使ってください。

使えるコントローラー

  • Windows で使える Xbox 形式(XInput)のゲームパッド。Xbox のコントローラーや、多くの PC 用ゲームパッドが当てはまります。
  • PlayStation のコントローラーは、Windows の標準のままでは使えないことがあります。Steam から起動するなど、Xbox 形式に読み替える方法をお使いください。
